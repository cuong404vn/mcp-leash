# Security policy

mcp-leash is a security tool, so a way around a policy is a vulnerability. Thank you for reporting one privately.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private reporting instead:

1. Go to the [Security tab](https://github.com/cuong404vn/mcp-leash/security) of the repository.
2. Click **Report a vulnerability**.
3. Describe the policy, the tool call that got through (or the crash), the operating system and the mcp-leash version (`mcp-leash --version`).

The maintainer aims to reply within 7 days. Once a fix is released, the advisory is published with credit to you, unless you prefer to stay anonymous.

Known limitations are listed in the [threat model](docs/threat-model.md). A new way to exploit one of them is still worth reporting.

## Supported versions

Until 1.0, only the latest release receives security fixes.
